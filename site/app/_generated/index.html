First response, fixed identity

The manifest identifies first-use bytes.

The digest detects later changes. It does not authenticate the publisher or content. You remain responsible for choosing trustworthy source URLs.

  1. 01

    Lock

    Review each URL, then run lock. It accepts the first response and writes its SHA-384 digest atomically.

  2. 02

    Verify

    Default verify checks materialized files offline. Run verify --all-platforms to check every locked cache variant.

  3. 03

    Sync

    Sync checks the destination first, then the cache, then the network. Cached or remote bytes must match the lock before the destination changes.
